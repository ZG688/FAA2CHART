============================================================
Tier B Screenshot File Documentation
============================================================

1. Total Number of Screenshot Files
   - pdf_screenshot/ directory: 150 screenshots (renamed by airway code)

2. Naming Convention
   - Renamed screenshot format: {index}_pdf_screenshot_{airway_code}.png
     Example: 01_pdf_screenshot_G575.png
              61_pdf_screenshot_A332.png

3. Correspondence with the Registration Table
   - The screenshot files are sequentially aligned with the airway records in the registration table (tierB_labels.xlsx) in chronological order.
   - Column 6 (pdf_screenshot) of the registration table records the relative path to the corresponding screenshot for each airway.
   - The 150 screenshots under pdf_screenshot/ correspond to rows 2–151 of the registration table.

4. Notes
   - The screenshot files are used for manual annotation verification, ensuring traceability of airway point registration.
   - The renamed screenshot paths have been written into the pdf_screenshot column of the registration table.
   - Some screenshots may contain content spanning multiple PDF pages due to cross‑page records.
